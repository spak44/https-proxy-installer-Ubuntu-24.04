HTTPS-прокси для Firefox

Версия 1.2 от 21.10.2026. ОС: Ubuntu 22.04 или 24.04. В примерах SSH-порт — 22; замените его, если у вас другой. Скрипт рассчитан на сервер с Amnezia без ранее установленного Squid/stunnel. Он не управляет Docker, контейнерами, SSH и настройками Amnezia. Устанавливает пакеты из репозиториев Ubuntu и Certbot из PyPI в отдельное Python-окружение. Не выполняет полное обновление ОС.

Исправления: добавлено ожидание ответа Squid с повтором при обрыве/пустом ответе и временной ошибке; отключён ICMP pinger (pinger_enable off), которому не нужны дополнительные права в этой схеме; тест продления выполняется без случайного ожидания Certbot.

В версии 1.2 добавлена Ubuntu 24.04: сохранена установка Certbot в отдельное Python-окружение; для активного штатного профиля AppArmor Squid добавляются точечные разрешения на конфигурацию, парольный файл и каталог журнала. AppArmor остаётся включённым. Если профиль отличается от ожидаемого, установка остановится с пояснением.

1. Загрузить скрипт

Скачайте install-https-proxy.sh на компьютер. В Windows откройте PowerShell в папке с файлом и выполните:

scp -P 22 .\install-https-proxy.sh root@IP_НОВОГО_СЕРВЕРА:/root/
ssh -p 22 root@IP_НОВОГО_СЕРВЕРА

Пароль SSH вводится только на вашем компьютере; символы при вводе не показываются. При первом подключении сверяйте отпечаток SSH-ключа с данными сервера/панели провайдера. Если OpenSSH на компьютере отсутствует, можно загрузить файл через SFTP в используемом SSH-клиенте и открыть его терминал.

2. Запустить на сервере

bash /root/install-https-proxy.sh

Сначала введите публичный IPv4 нового сервера из панели VPS. Старый IP в скрипте больше не задан. Можно передать IP при запуске: bash /root/install-https-proxy.sh IP_НОВОГО_СЕРВЕРА.

Скрипт сообщит выбранный порт: 443, а если занят — 8443 или 9443. Затем попросит email для учётной записи центра сертификации и YES (можно yes) для принятия условий Let's Encrypt и начала установки.

TCP 80 должен быть свободен и доступен из интернета для первичного выпуска и всех продлений сертификата. Если в панели VPS включён отдельный firewall, разрешите входящие TCP 80 и выбранный порт прокси. Скрипт добавляет эти два разрешения в UFW только если UFW уже включён; не сбрасывает firewall и не включает его заново. При других правилах фильтрации проверка сертификата может остановиться — тогда нужен разбор ошибки.

Во время установки появится обычный вывод пакетного менеджера. При успешном завершении будет SUCCESS. Скрипт проверяет доверие к сертификату по IP, обязательность пароля, отклонение неверного пароля, запрет доступа к loopback, CONNECT к example.com:443 и тестовое продление сертификата. Внешняя доступность проверяется отдельно в Firefox.

Логин — firefox. Случайный пароль создаётся на вашем сервере. Посмотреть его:

cat /root/browser-proxy-access.txt

Не присылайте этот файл или скриншот с паролем в чат.

3. Подключить Firefox на компьютере

Выход из SSH:

exit

В PowerShell на компьютере скачайте созданный файл настройки:

scp -P 22 root@IP_НОВОГО_СЕРВЕРА:/root/browser-proxy.pac "$env:USERPROFILE\Downloads\browser-proxy.pac"

В Firefox откройте Настройки → Основные → Настройки сети → Настроить. Выберите URL автоматической настройки прокси и укажите локальный адрес файла, например:

file:///C:/Users/Denis/Downloads/browser-proxy.pac

Замените Denis на фактическое имя папки своего пользователя Windows. Нажмите Перезагрузить, если кнопка доступна, затем ОК. Если расширение управляет прокси, сначала отключите в нём управление, чтобы оно не переопределяло настройки.

Откройте обычный HTTPS-сайт, введите логин firefox и созданный пароль. Затем проверьте внешний IP через https://api.ipify.org — при подключении по IPv4 ожидается IP_НОВОГО_СЕРВЕРА. Если у VPS есть IPv6, исходящий адрес может быть IPv6 сервера.

PAC использует именно HTTPS IP:порт: соединение Firefox с прокси защищается TLS. Обычное поле «HTTPS-прокси» в ручных настройках не следует считать равнозначной настройкой TLS до прокси. Сертификаты сайтов не подменяются, устанавливать свой корневой сертификат на компьютер не требуется.

PAC направляет веб-запросы через прокси без добавленного варианта DIRECT. Это не системный VPN: другие приложения и отдельный трафик браузера, например WebRTC, могут идти отдельно. Локальные сайты по частным IP через этот прокси недоступны. Для отключения выберите в Firefox «Без прокси» либо верните прежний режим.

Обслуживание

Сертификат на IP действует около 6 дней. Таймер проверяет необходимость продления каждые 6 часов. После успешного продления перезапускается только TLS-служба прокси; активные подключения прокси могут кратко прерваться. Amnezia не перезапускается. Порт 80 должен оставаться доступен, хотя Certbot слушает его только во время проверки.

Проверить службы и таймер:

systemctl status browser-proxy-squid browser-proxy-tls browser-proxy-renew.timer --no-pager
systemctl list-timers browser-proxy-renew.timer --no-pager
journalctl -u browser-proxy-renew.service -n 50 --no-pager

Остановить прокси и продления:

systemctl disable --now browser-proxy-tls.service browser-proxy-squid.service browser-proxy-renew.timer

Это не удаляет файлы, пакеты, сертификаты и правила UFW. Штатные службы пакетов squid.service и stunnel4.service специально замаскированы: вместо них используются отдельные browser-proxy-*; не снимайте маски без проверки конфигурации.

Если установка остановилась

Пришлите последние 20–30 строк ошибки без паролей. Не переустанавливайте Amnezia и не отключайте firewall целиком. Скрипт останавливается при занятом порте 80, обнаружении чужой установки Squid/stunnel или ошибке проверки. Уже установленные файлы и пакеты сохраняются; автоматического отката нет. После частично выполненной установки с работающими службами повторный запуск может остановиться на проверке портов — сначала разберём исходную ошибку.

Проверены разбор конфигурации Squid 6 из пакета Ubuntu 24.04, синтаксис Bash и встроенных Python-фрагментов, а также проверки запуска на локальном TLS-стенде с имитацией задержки и обрыва соединения. Реальная установка, выпуск сертификата и доступ из вашей сети требуют запуска на VPS и проверки Firefox.
